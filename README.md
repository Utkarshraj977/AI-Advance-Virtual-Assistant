# AI Voice Assistant

A browser-based virtual assistant built with React, Vite, and the Gemini API. It accepts voice commands, generates AI responses, and uses browser speech capabilities for a conversational experience.

## Features

- Voice input and spoken responses
- Gemini-powered answers
- Responsive React interface
- Dedicated listening and speaking states

## Tech stack

React, Vite, JavaScript, Gemini API, Web Speech API

## Run locally

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_KEY` in `.env`. Never commit the real key.
